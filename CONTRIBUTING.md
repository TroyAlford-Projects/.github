# Contributing

## Workflow

- All changes to the default branch (`main`) land through a **pull request**.
- Commits must be **signed** (SSH or GPG).
- Use **Conventional Commits** for PR titles and commit messages:
  `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`.
- **Squash merge** is the only enabled merge method; the branch is deleted on
  merge.

## Before opening a pull request

- Run the repository's lint, typecheck, and test tasks locally.
- Keep the change focused; one logical change per PR.
- Update docs and tests alongside code.
